# 萝卜地牢 0.85 更新日志

> 本文为 0.8.5 版本发布说明草案。以下内容记录本版本计划纳入的改动，具体数值和实现细节以最终版本为准。

## 全新内容

- 接入全新的萝卜地牢 UI 风格与界面组件。
- 调整选人界面，改善角色选择、信息展示和操作布局。
- 新增多种附魔、刻印和诅咒。
- 新增投掷武器系统，以及投掷武器独享的附魔、刻印和诅咒。
- 新增流浪者皮肤。
- 新增骑士皮肤（战士）。
- 暂不实装密使皮肤（美术效果尚未达到要求）。
- 诗人皮肤暂缓，等待适配角色。

## 地牢与生成

- 改进查种器对分支地牢的支持。现在可以正确查询二区之后各分支楼层的物品生成情况，减少查询结果与实际地牢的偏差。
- 第 3 层通往苔藓洞窟的门改为单向门：只能从苔藓洞窟返回该处，不能从地牢一侧向上进入苔藓洞窟。
- 修复透视水晶箱内物品生成和显示异常。
- 修复杂散未能正确生成一个“+1、诅咒”的元素戒指的问题。

## 物品与机制调整

- **塑形玻璃**：修复其导致灵能弓伤害始终为 0 的问题。
- **砥砺锋芒**：移除月华英雄限制。任何英雄获得该天赋后都可以鉴定装备。
- **毒芹**：中毒改为特殊中毒，持续时间延长且不会自然衰减。
- **狗腿**：移除攻击功能。投掷后无法捡回，会持续吸引附近怪物；被第一个怪物触及后消失。
- **简易投石索**：默认鉴定、可堆叠；消耗一颗石子发射，使用石子的飞行贴图，并具有更快的投射速度。
- **律法残页**：效果改为接近《黑暗地牢》光明卷轴的表现形式，提升光照与视觉反馈；修复其参与炼金配方时的逻辑问题。
- **金属碎片**：现在可以消耗炼金能量熔炼为液金。
- **灵魂余烬**：可将投掷位置的地形变为灰烬格，并对 3×3 范围内敌人施加怨魂缠身。
- **怨魂缠身**：固定降低 30% 命中和闪避，并与其他效果以加法叠加。
- **骨堆**：音效改为骨头爆裂；掉落率由 33% 调整为 20%。骨爪和骨矛改为每局限量掉落，每局翻开多个骨堆也最多各掉落一次，以略微提高金币获取量。

## 执行者天赋

- **4-3 影子战术**：任意中立生物或执行者盟友死亡后，以死亡地点为中心，对 3×3 范围内敌人造成 25/37/48/50 点伤害（对应 1/2/3/4 级）。
- **4-4 扫荡模式**：当执行者视野范围内的怪物数量不超过 1/1/1/2 只时，移动速度提升 33%/66%/100%/100%，攻击速度提升 17%/33%/50%/50%。

## Bug 修复

- 修复圆球无法投掷种子和蜡烛的问题。
- 修复杂散与战士纹章的兼容性问题。
- 修复蛇咬挑战中怪物文本描述异常，恢复为正常描述。
- 修复共鸣附魔与共鸣刻印导致游戏闪退的问题。
- 修复透视水晶箱物品相关异常。

## 版本说明

0.8.5 是一次大型内容与系统更新，涵盖 UI、地牢生成、分支楼层查询、投掷武器、装备效果、天赋、皮肤以及多项稳定性修复。部分美术内容和数值仍可能在正式发布前调整。
