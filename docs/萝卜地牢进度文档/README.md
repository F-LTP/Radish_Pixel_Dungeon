# 萝卜地牢进度文档

本文件夹用于记录「萝卜地牢」方向的开发进度、规划与历史。它是了解本项目开发节奏与方向的入口，人类开发者与 AI Agent 均可在开始相关工作时参考。

## 目录结构

- **`待办/`** — 当前与近期要处理的 bug、功能与设计反馈清单，按版本与主题分类，是「接下来该做什么」的答案所在地。
- **`重构计划/`** — 已形成的架构重构设计方案（如伤害系统、Char.java 事件系统迁移等）。部分方案尚未实施或处于暂停状态，方案内会标注当前状态，实施前请先阅读。
- **`过去版本/`** — 历史版本的更新计划与 bug 列表、旧角色设计等归档，用于追溯与对照，一般无需修改。
- **`bugs/`** — bug 台账，按状态分为 `未修复/` 与 `已修复/` 两个子目录，用于集中跟踪 bug 的修复进度。

## 使用说明

- 想了解**当前**进度与待办，看 `待办/`。
- 想了解**未来**架构方向，看 `重构计划/`（注意其中「未开始/暂停」的方案）。
- 想追溯**历史**版本情况，看 `过去版本/`。
- 想跟踪**bug** 修复状态，看 `bugs/`（未修复 / 已修复）。
- 各子目录内的文档多数为任务清单（`- [ ]` / `- [x]`），新增任务时请遵循文件内既有的命名与格式约定。
